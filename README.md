**Optimizator** — это десктопное приложение для анализа и оптимизации автозагрузки Windows, которое помогает ускорить загрузку системы и улучшить её отзывчивость.

Со временем компьютер обрастает программами, прописывающими себя в автозапуск без ведома пользователя. Это замедляет старт Windows и снижает производительность. Optimizator решает эту проблему, предоставляя удобный инструмент для управления автозагрузкой на основе данных из специализированной базы.

##  Проблема и решение

**Проблема:**
Эффективность работы Windows во многом определяется скоростью её загрузки. Ключевой фактор, замедляющий этот процесс — множество программ и служб, автоматически запускающихся при старте системы. Со временем компьютер пользователя «обрастает» приложениями, которые добавляют себя в автозагрузку без явного уведомления и острой необходимости. Это приводит к:
- увеличению времени запуска,
- снижению отзывчивости системы в первые минуты работы,
- общему ухудшению пользовательского опыта.

**Решение:**
Optimizator анализирует все точки входа автозагрузки Windows и сверяет найденные программы с базой данных, которая содержит информацию о влиянии каждого приложения на производительность, его репутацию и рекомендации по отключению или отложенному запуску.

##  Возможности

- **Сбор данных об автозагрузке** — сканирование реестра, папок автозагрузки и запланированных задач.
- **Интеграция с базой данных** — хранение и актуализация сведений о программах.
- **Анализ влияния на запуск** — оценка того, насколько каждая программа замедляет старт системы.
- **Рекомендации по оптимизации** — безопасные советы: отключить, отложить или оставить.
- **Удобный интерфейс (WPF)** — современное Windows-приложение с Material Design.

# ⚙️ Установка и запуск

### Предварительные требования

- [.NET 9.0 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/9.0)
- [PostgreSQL](https://www.postgresql.org/download/) (рекомендуется pgAdmin 4 для управления)
- Любая среда разработки (Visual Studio 2022+, Rider или VS Code)

### Настройка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/n1k1tashvelv-wq/optimizator.git
   cd optimizator



##Использование
1. Запустите Optimizator.
2. Нажмите кнопку «Анализировать» — приложение просканирует автозагрузку системы.
3. Изучите список найденных программ и их влияние на запуск.
4. Следуйте рекомендациям:
   · Отключить — убрать из автозагрузки полностью.
   · Отложить — запустить через некоторое время после старта системы.
   · Оставить — программа важна и не замедляет запуск.
5. Примените изменения и перезагрузите компьютер, чтобы оценить эффект.
```
